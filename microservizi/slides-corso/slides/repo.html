Il repository del corso

github.com/mg-i-roc-maz/corsi

Un solo repo per tutto il corso. Si clona una volta, poi a ogni lezione si aggiorna con git pull.

git clone https://github.com/
  mg-i-roc-maz/corsi
cd corsi/microservizi
git pull  # a ogni lezione

In ogni cartella di lezione: slides, start (si lavora qui), solution.

Il repo corsi contiene anche altri corsi dell'ITS: gli studenti devono lavorare solo dentro microservizi. Le cartelle delle lezioni 2-8 vengono pubblicate prima di ciascuna lezione; la colonna Stato va aggiornata man mano. Se qualcuno ha modificato i file in start e git pull dà conflitto, la soluzione più semplice è git stash prima del pull.
