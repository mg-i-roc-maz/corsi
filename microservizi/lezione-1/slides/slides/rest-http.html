Che cosa viaggia sulla rete

Richiesta

POST /products HTTP/1.1
Host: localhost:3001
Content-Type: application/json

{ "name": "Cuffie",
  "priceCents": 5990,
  "stock": 8 }

Risposta

HTTP/1.1 201 Created
Location: /products/p-4
Content-Type: application/json

{ "id": "p-4",
  "name": "Cuffie", ... }

Prima riga: metodo e percorso, oppure codice di stato

Header: informazioni sul messaggio, una per riga

Corpo: i dati, dopo una riga vuota

È esattamente il testo che scriviamo nei file .http di REST Client, che a sua volta mostra la risposta in questo formato. Content-Type dice di che tipo è il corpo: senza application/json Fastify non interpreterebbe il JSON. HTTP/2 e HTTP/3 codificano gli stessi elementi in binario, ma il modello resta questo.
