Fastify in cinque minuti

Un framework web per Node.js, progetto della OpenJS Foundation. Prende una richiesta HTTP, trova la funzione giusta e spedisce la risposta. Tutto il server sta in quattro righe:

import Fastify from "fastify";
const app = Fastify({ logger: true });
app.get("/health", async () => ({ status: "ok" }));
await app.listen({ port: 3001 });

Istanza

app: il server. In app.ts

Rotte

app.get, post, put, delete. In routes.ts

Schema

Regole JSON Schema sui dati. In schemas.ts

Plugin

Gruppi di rotte aggiunti con app.register

Far notare che productRoutes in routes.ts è un plugin: una funzione async che riceve app e registra rotte. In app.ts viene aggiunto con app.register(productRoutes). Nel monolite catalogRoutes e orderRoutes sono due plugin nello stesso processo: è la forma "modulare" del monolite. logger: true attiva i log in JSON (libreria pino): sono le righe {"level":30,...} che si vedono nel terminale.
