Extra 2 · base · 10'

Ordinamento

Aggiungi a GET /products il parametro sort. Accetta solo:

ValoreOrdine
name · -nameNome, A→Z o Z→A
price · -pricePrezzo, crescente o decrescente

Altri valori: 400. Con l'esercizio 1, si ordina prima di paginare.

Suggerimenti: enum nello schema; array.sort((a, b) => ...); a.name.localeCompare(b.name, "it").

Atteso

?sort=-price
→ p-3, p-1, p-2

?sort=colore
→ 400

Soluzione. Nello schema della query: sort: { type: "string", enum: ["name", "-name", "price", "-price"] }. Nella rotta, dopo store.list(q): if (sort) { const desc = sort.startsWith("-"); const field = desc ? sort.slice(1) : sort; all.sort((a, b) => { const cmp = field === "price" ? a.priceCents - b.priceCents : a.name.localeCompare(b.name, "it"); return desc ? -cmp : cmp; }); }. Aggiornare il tipo ListQuery con sort?: string. store.list() restituisce sempre un array nuovo, quindi ordinarlo non modifica i dati dello store.
