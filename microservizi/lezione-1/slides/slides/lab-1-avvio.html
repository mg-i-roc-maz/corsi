1.1 · Avvia il monolite

cd monolith
npm install
npm run dev

npm install scarica le dipendenze, solo la prima volta. npm run dev avvia il server e lo riavvia a ogni salvataggio.

È pronto quando vedi:

"msg":"Server listening at
http://127.0.0.1:3000"

Lascia questo terminale aperto e aprine un secondo con il pulsante + per i comandi successivi.

Errore più comune: lanciare npm install dalla cartella sbagliata. Il prompt del terminale deve terminare con lezione-1/start/monolith.
