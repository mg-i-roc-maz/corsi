2.1 · Avvia il servizio catalog

Ferma il monolite con Ctrl+C. Il nuovo servizio è un'applicazione indipendente, sulla porta 3001.

cd ../services/catalog
npm install
npm run dev

Con http/catalog.http: GET /health e GET /products funzionano già.

Prova GET /products/p-1:

501 Not Implemented
{"error":"TODO 1: da implementare"}

È il tuo punto di partenza: quattro TODO da completare.

Il percorso cd ../services/catalog vale se si è nella cartella monolith. In alternativa aprire un nuovo terminale e partire da lezione-1/start.
