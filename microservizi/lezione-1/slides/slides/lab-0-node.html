0.5 · Se node -v è sotto la 22

La via più semplice è il Dev Container (0.4). Se vuoi Node sul tuo computer, usa un version manager: installa più versioni e passi da una all'altra.

Mac e Linux · nvm

Installa nvm con il comando indicato su github.com/nvm-sh/nvm, riapri il terminale, poi:

nvm install 22
nvm use 22
nvm alias default 22

Su Mac, in alternativa: brew install node@22

Windows

Con nvm-windows (github.com/coreybutler/nvm-windows), da un terminale come amministratore:

nvm install 22
nvm use 22

Oppure l'installer LTS da nodejs.org, o: winget install OpenJS.NodeJS.LTS

Poi chiudi e riapri il terminale e ricontrolla: node -v deve dare v22 o successiva.

Nel repo c'è il file .nvmrc con scritto 22: dentro la cartella start basta digitare nvm install e poi nvm use, senza numero di versione. La versione LTS attuale su nodejs.org può essere più recente della 22 (per esempio la 24): va bene, il progetto richiede almeno la 22. Se dopo l'installazione node -v mostra ancora la versione vecchia, il terminale non è stato riaperto oppure c'è un'altra installazione di Node che viene prima nel PATH: which node (Mac, Linux) o where node (Windows) mostra quale viene usata.
