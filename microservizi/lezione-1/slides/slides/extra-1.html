Paginazione

Con migliaia di prodotti, GET /products sarebbe enorme. Aggiungi due parametri di query:

ParametroSignificatoDefault, limiti
limitQuanti restituirne20, da 1 a 50
offsetQuanti saltarne0, da 0 in su

E l'header X-Total-Count con il totale prima della paginazione.

Suggerimenti: uno schema per la query string (default e type integer convertono da soli); array.slice(inizio, fine).

Atteso

?limit=2
→ 2 prodotti, X-Total-Count: 3

?limit=2&offset=2
→ solo il terzo

?limit=500
→ 400

Per riflettere: e se tra pagina 1 e pagina 2 qualcuno cancella un prodotto?

Soluzione. In schemas.ts: export const listQuerySchema = { type: "object", properties: { q: { type: "string" }, limit: { type: "integer", minimum: 1, maximum: 50, default: 20 }, offset: { type: "integer", minimum: 0, default: 0 } } } as const; In routes.ts: type ListQuery = { q?: string; limit: number; offset: number }; e la rotta app.get("/products", { schema: { querystring: listQuerySchema } }, async (request, reply) => { const { q, limit, offset } = request.query; const all = store.list(q); reply.header("X-Total-Count", all.length); return all.slice(offset, offset + limit); }). Riflessione: con l'offset un elemento può essere saltato o ripetuto se l'elenco cambia tra una pagina e l'altra; per questo esiste la paginazione a cursore (?after=p-20).
