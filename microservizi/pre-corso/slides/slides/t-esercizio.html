Costruisci il tuo negozio

1. Nella home crea la cartella negozio ed entraci
2. Dentro crea catalogo e ordini
3. In catalogo crea prodotti.txt
4. Torna in negozio ed elenca tutto con ls
5. Rinomina ordini in vendite
6. Cancella prodotti.txt

Risultato atteso

~/negozio
├─ catalogo  (vuota)
└─ vendite

Ogni volta che sei in dubbio: pwd e ls.

Soluzione: cd ~ ; mkdir negozio ; cd negozio ; mkdir catalogo ordini ; touch catalogo/prodotti.txt (in PowerShell New-Item catalogo/prodotti.txt) ; ls ; mv ordini vendite ; rm catalogo/prodotti.txt. Variante: fare il punto 3 entrando in catalogo con cd e tornando su con cd .. per esercitare i percorsi relativi.
