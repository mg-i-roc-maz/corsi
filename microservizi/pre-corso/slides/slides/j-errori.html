Gli errori più comuni

ErroreSbagliatoGiusto
Virgolette singole{ 'name': 'a' }{ "name": "a" }
Chiave senza virgolette{ name: "a" }{ "name": "a" }
Virgola finale{ "a": 1, }{ "a": 1 }
Virgola mancante{ "a": 1 "b": 2 }{ "a": 1, "b": 2 }
Commenti{ "a": 1 // nota }Non sono ammessi
True maiuscolo{ "ok": True }{ "ok": true }

VS Code sottolinea in rosso gli errori nei file .json: è il controllo più rapido.

Quando il server riceve un JSON non valido risponde 400 Bad Request: lo vedremo nella lezione 1. Errore tipico nel corso: copiare un oggetto JavaScript con chiavi senza virgolette dentro un file .http. In alternativa a VS Code, si può incollare il testo in un validatore JSON online.
