Parte 1 · Terminale

Che cos'è il terminale

Un modo di usare il computer scrivendo comandi invece di cliccare. Il programma che li interpreta si chiama shell.

Mac

App Terminale, shell zsh

Linux

Terminale, di solito bash

Windows

PowerShell, o Git Bash

VS Code

Terminale integrato: Ctrl+` o Cmd+`

studente@pc ~ % pwd
/Users/studente

Il testo prima del cursore si chiama prompt: indica utente, computer e cartella corrente. Useremo sempre il terminale integrato di VS Code, così editor e comandi stanno nella stessa finestra. Nel Dev Container il terminale è bash, anche su Windows.
