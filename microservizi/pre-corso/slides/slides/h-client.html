Client e server

Client

browser, app, curl, un altro servizio

richiesta

risposta

Server

un programma in ascolto su una porta

Il client chiede, il server risponde. HTTP è la lingua comune: regole su come scrivere richieste e risposte.

Il server non contatta mai il client di sua iniziativa: risponde solo a una richiesta. Nel corso ogni servizio è un server (catalog, orders...), e quando orders chiama catalog diventa a sua volta un client. La porta è come il numero dell'interno di un ufficio: sullo stesso computer possono girare più server su porte diverse (3000, 3001).
