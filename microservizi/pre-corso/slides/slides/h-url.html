Parte 2 · HTTP

Anatomia di un URL

URL · Uniform Resource Locator: dice dove si trova una risorsa e come raggiungerla.

URI · Uniform Resource Identifier: la identifica. Ogni URL è anche un URI.

http://localhost:3001/products/p-1?q=mouse

ParteNell'esempioA cosa serve
SchemahttpIl protocollo; https se cifrato
HostlocalhostIl computer: localhost è il tuo
Porta3001Quale programma su quel computer
Percorso/products/p-1Quale risorsa
Query?q=mouseParametri extra: filtri, ricerche
URI è il concetto più generale: un nome univoco per una risorsa. Un URL è un URI che contiene anche il modo di raggiungerla (schema e host). Esempio di URI che non è un URL: urn:isbn:0451450523, che identifica un libro ma non dice dove scaricarlo. Nel parlato si usano spesso come sinonimi; nella documentazione delle API REST si incontrano entrambi. Se la porta non è scritta si usano quelle standard: 80 per http, 443 per https. Più parametri di query si separano con &: ?q=mouse&limit=10. Domanda: in https://github.com/mg-i-roc-maz/corsi qual è l'host e qual è il percorso?
