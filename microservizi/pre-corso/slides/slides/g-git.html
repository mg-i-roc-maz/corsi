Parte 4 · Git

Git in tre comandi

Git tiene la storia dei file di un progetto. Il materiale del corso è su GitHub: per seguirlo ti bastano tre comandi.

git clone https://github.com/mg-i-roc-maz/corsi

Scarica il repo, una volta sola

git pull

Scarica le novità, a ogni lezione

git status

Mostra che cosa hai modificato

git pull si lancia dentro la cartella corsi. Se segnala un conflitto con i tuoi file: git stash e poi di nuovo git pull.

Git si installa da git-scm.com; su Mac viene proposto la prima volta che si scrive git nel terminale. Non serve un account GitHub per clonare un repo pubblico. git stash mette da parte le modifiche locali; si recuperano con git stash pop. Commit e branch non servono per seguire il corso.
