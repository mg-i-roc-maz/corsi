Parte 2 · HTTP

I codici di stato: com'è andata

2xx

Tutto bene

200 OK
201 Created
204 No Content

3xx

Vai altrove

301 Moved
304 Not Modified

4xx

Errore del client

400 Bad Request
401 Unauthorized
404 Not Found

5xx

Errore del server

500 Internal
503 Unavailable

Basta la prima cifra per capire di chi è il problema: 4 hai sbagliato tu, 5 ha sbagliato il server.

404 è il più famoso: la risorsa non esiste. 401 significa che serve autenticarsi. Il 304 tornerà nella lezione 6 sulla cache HTTP. Domanda: se scrivo male l'indirizzo di una pagina, che codice ottengo? E se il server è spento? (In quel caso nessun codice: la connessione viene rifiutata, come vedremo nel corso.)
