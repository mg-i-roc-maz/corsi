Parte 2 · HTTP

curl: HTTP dal terminale

Una GET

curl https://jsonplaceholder.typicode.com/todos/1

Con gli header della risposta

curl -i https://jsonplaceholder.typicode.com/todos/1

Una POST con un corpo JSON

curl -X POST https://jsonplaceholder.typicode.com/posts \
  -H "Content-Type: application/json" \
  -d '{"title":"ciao","userId":1}'

-i mostra gli header · -X sceglie il metodo · -H aggiunge un header · -d invia un corpo. Su Windows scrivi curl.exe.

Su Windows PowerShell 5, curl è un alias di un altro comando (Invoke-WebRequest) con opzioni diverse: per questo si scrive curl.exe. Le virgolette del corpo JSON in PowerShell sono scomode: per la POST conviene il terminale del Dev Container, Git Bash o REST Client in VS Code. La barra rovesciata a fine riga serve solo ad andare a capo nei terminali Mac e Linux.
