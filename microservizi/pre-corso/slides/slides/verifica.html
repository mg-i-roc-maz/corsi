Quattro domande prima di chiudere

1. Che differenza c'è tra un percorso assoluto e uno relativo?

2. Una risposta 404 e una 500: di chi è la colpa?

3. Con quale metodo HTTP crei un nuovo ordine?

4. Perché { name: 'a' } non è JSON valido?

Risposte. 1: l'assoluto parte dalla radice (/), il relativo dalla cartella in cui sei. 2: 404 è un errore del client (la risorsa non esiste), 500 un errore del server. 3: POST. 4: la chiave deve stare tra virgolette doppie e anche il valore usa virgolette singole invece di doppie.
