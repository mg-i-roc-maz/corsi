Parte 3 · JSON

Che cos'è JSON

JavaScript Object Notation: un formato di testo per rappresentare dati. Lo leggono le persone e tutti i linguaggi di programmazione.

È il formato con cui i nostri servizi si scambiano prodotti, ordini ed eventi.

{
  "id": "p-1",
  "name": "Tastiera",
  "priceCents": 8990,
  "available": true,
  "tags": ["pc", "gaming"]
}

Un oggetto sta tra graffe { } ed è fatto di coppie chiave: valore, separate da virgole.

Le chiavi sono a sinistra, sempre tra virgolette doppie; i valori a destra possono essere di vari tipi (prossima slide). Un oggetto JSON assomiglia a un oggetto JavaScript, ma le regole sono più rigide: per questo un JSON "quasi giusto" non viene accettato.
