## Programma del corso

- Architettura client–server
- HTTP/HTTPS: metodi (GET, POST), status code
- Differenze tra REST e web app tradizionali
- JSON come formato dati per il web
- HTML: strutture di base, tabelle, form e input
- CSS base per migliorare la leggibilità
- JavaScript per l’accesso e la manipolazione dei dati
  - Variabili e funzioni essenziali
  - Uso della Fetch API
  - Chiamate REST e parsing di JSON
  - Visualizzazione dati con chart.js / plotly.js
- Concetti di backend
  - API per dati e modelli
  - Microservizi
  - Introduzione a Python con FastAPI e Flask
- API che restituiscono:
  - Risultati di analisi
  - Output di modelli di Machine Learning
- Il web come interfaccia per:
  - Pipeline di dati
  - Sistemi di Business Intelligence (BI)
  - Servizi cloud
